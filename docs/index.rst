jnkepler
========

jnkepler is a differentiable N-body model for multi-planet systems. These
tutorials assume basic Python and orbital mechanics, but no prior experience
with NumPyro or NUTS. Follow parts 1–3 in one Python session to fit transit
times, define a probability model, and sample its posterior. Part 4 introduces
other observables and orbital models; part 5 guides you to complete example
notebooks.
